# 🧮 Calculator

A modern and responsive Calculator built using HTML, CSS, and JavaScript. The application performs basic arithmetic operations through a clean, interactive, and user-friendly interface with smooth button animations.

## 🚀 Features

- Addition, Subtraction, Multiplication, and Division
- Clear (AC) functionality
- Delete (Backspace) functionality
- Responsive design
- Smooth button animations
- Modern user interface
- Keyboard-friendly layout (if supported)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📁 Project Structure

```
Calculator/
│── index.html
│── style.css
│── script.js
│── README.md
```

## ▶️ Installation & Usage

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/Calculator.git
   ```

2. Open the project folder.

3. Open `index.html` in your preferred web browser.

4. Perform calculations using the calculator interface.

## 📌 Operations Supported

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🗑️ Clear Screen
- ⌫ Delete Last Entry
